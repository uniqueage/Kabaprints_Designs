# Kabaprints — Printshop + Design

Modern, multi-page marketing website for **Kabaprints**, a marketing and printing agency
specialising in advert production.

Built with **Next.js (App Router) + TypeScript + Tailwind CSS**.

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Hero carousel (rotating print designs with details), headline & subheadline, 7 service tags, vision, testimonials, open hours |
| `/services` | All services overview |
| `/services/[slug]` | Dedicated page for each of the 7 service tags: Transfer Print, Screen Print, Clean Banners, Van Display, Engraving, Signage, Others |
| `/quote` | Quote page — what it is, printable materials, available sizes & colours, sample projects, quote request form |
| `/design` | "Need a Design?" — design services, process and deliverables |
| `/upload` | Upload customer artwork (PNG, JPG/JPEG, PDF, SVG) via drag & drop |
| `/portfolio` | **Kabaprints works** — before/after product displays + works gallery |
| `/search` | Site-wide search (also available from the header) |
| `/sign-in` | Customer sign-in |
| `/contact` | Phone, WhatsApp and open hours |

## Brand

Colours are taken from the Kabaprints header/logo:

- **Kaba** — slate grey `#96A1A6`
- **prints** — coral serif italic `#E4795B`
- **PRINTSHOP + DESIGN** — blue `#1E6FA9`

Floating WhatsApp and Call buttons (`0803 296 1171`, `0915 281 2526`) appear on every page.
Opening hours: **9:00 am – 7:00 pm, Mondays – Saturdays**.

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint    # eslint
```

Product mockup artwork in `public/images` is generated by `node scripts/gen-images.mjs`.

> Note: file uploads and form submissions are client-side demos (no backend attached yet) —
> each action hands the customer off to WhatsApp/phone to complete the order.
